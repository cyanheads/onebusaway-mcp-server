# 0.2.0 — 2026-09-24

Inputs that previously reached OneBusAway and now fail argument validation with `InvalidParams` before any upstream request are listed under **Changed**.

## Added

- **`onebusaway_get_stop_context`** ([#24](https://github.com/cyanheads/onebusaway-mcp-server/issues/24)) — `stop`, `currentTime`, `arrivals`, and `alerts` from one arrivals-and-departures request: arrivals in the `onebusaway_get_arrivals` shape, alerts in the `onebusaway_get_alert` shape. Takes the same input as `onebusaway_get_arrivals`; `stop` omits `routeIds` and is `null` when upstream leaves it out.
- **`test:coverage`** ([#27](https://github.com/cyanheads/onebusaway-mcp-server/issues/27)) — `vitest run --coverage` on Istanbul against the framework thresholds, excluding only `src/index.ts`.

## Changed

- **`minutesBefore` / `minutesAfter`** ([#28](https://github.com/cyanheads/onebusaway-mcp-server/issues/28)) — Integers 0–60 and 0–240 on `onebusaway_get_arrivals` and `onebusaway_get_stop_context` (defaults 5 and 35). Now rejected: negative, fractional, or out-of-range values such as `-1`, `2.5`, `61`, `241`.
- **Empty-window notice** ([#28](https://github.com/cyanheads/onebusaway-mcp-server/issues/28)) — Suggests raising `minutesAfter` only below the 240 cap; at the cap it points to `onebusaway_get_schedule_for_stop`.
- **`onebusaway_get_trip` `serviceDateMs`** ([#31](https://github.com/cyanheads/onebusaway-mcp-server/issues/31)) — Non-negative integer. Now rejected: negative or fractional values such as `-1` and `1.5`.
- **Schedule `date`** ([#32](https://github.com/cyanheads/onebusaway-mcp-server/issues/32)) — `onebusaway_get_schedule_for_stop` and `onebusaway_get_schedule_for_route` take a real `YYYY-MM-DD` calendar date; omitted or `""` still means today. Now rejected: epoch or all-digit strings (`20260924`), unpadded dates (`2026-9-3`), datetimes, impossible dates (`2026-02-30`, `2026-02-29`), other formats (`09/24/2026`), and values with surrounding or only whitespace.

## Fixed

- **`onebusaway_get_arrivals` `situations`** ([#29](https://github.com/cyanheads/onebusaway-mcp-server/issues/29)) — Includes alerts attached to the stop itself, not only those referenced by an arrival in the window; each alert listed once.
- **Upstream HTTP 400** ([#30](https://github.com/cyanheads/onebusaway-mcp-server/issues/30)) — Classified as a non-retryable `ValidationError` carrying OneBusAway's `fieldErrors` text, instead of a service-unavailable error.
