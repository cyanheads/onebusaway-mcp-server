# 0.4.0 — 2026-11-13

## Added

- **Stop lookups** include available served-route names, IDs, and agencies in the order of `routeIds` on the stop resource and the detail, location, and name-search tools. ([#54](https://github.com/cyanheads/onebusaway-mcp-server/issues/54))
- **`onebusaway_get_trip`** reports `status.activeTripId` and `status.blockTripSequence` and identifies the trip the status describes when it differs from the requested trip. ([#45](https://github.com/cyanheads/onebusaway-mcp-server/issues/45))

## Changed

- Require raw lookup IDs in tool arguments; percent-encoded aliases are rejected. Resource URIs retain standard URI encoding.
- **Read limits** allow up to 3,500 stops or 6,000 routes per search and report when a count, radius, or arrival window is clamped. Set `ONEBUSAWAY_CLAMP_LIMITS=false` to reject over-limit inputs. ([#50](https://github.com/cyanheads/onebusaway-mcp-server/issues/50))
- **Bun** now requires 1.4.4 or later.
- **Transit guide 1.1** documents stop-name and stop-code discovery, active-trip attribution, and arrival prediction limits.

## Fixed

- **Empty searches** remain successful and suggest another lookup path. Use `onebusaway_find_stops` for stop codes and location or agency lookups when route search comes up empty. ([#49](https://github.com/cyanheads/onebusaway-mcp-server/issues/49))
- **Arrival and agency output** distinguish predicted stop deviation from vehicle deviation, show signed stop sequence offsets, and label agency coverage spans as full widths. ([#52](https://github.com/cyanheads/onebusaway-mcp-server/issues/52))

## Security

- **Upstream lookup paths** confine validated IDs to one segment of the intended OneBusAway endpoint. ([#46](https://github.com/cyanheads/onebusaway-mcp-server/issues/46))
