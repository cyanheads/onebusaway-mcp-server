# 0.3.0 — 2026-10-26

## Added

- Expose the `onebusaway-guide` skill through MCP at `skill://onebusaway-guide/SKILL.md`.
- **Schedule selectors** filter stop departures by route and epoch interval, and route/block schedules by exact trip or GTFS departure interval, with before/after counts and complete selected trips ([#40](https://github.com/cyanheads/onebusaway-mcp-server/issues/40)).
- **Published transit guide** ships with plugins, npm, Docker, and MCPB, carrying identifier chains and interpretation gates.

## Changed

- **Plugin and MCPB configuration** forwards the instance URL, API key, rate limits, and log level; add Agent Plugins 1.0.0 root manifests.
- **Build tooling** syncs framework development guides and packaging checks; Bun package-manager and Docker images move from 1.4.2 to 1.4.4, with a one-day minimum dependency release age.

## Fixed

- **Agency-local times** resolve validated timezones per queried entity and alert scope, render explicit zone labels, and use UTC when unresolved or conflicting ([#38](https://github.com/cyanheads/onebusaway-mcp-server/issues/38)).
- **Schedule-date descriptions** distinguish stop query-time markers from explicit-date midnight markers while preserving upstream numbers ([#33](https://github.com/cyanheads/onebusaway-mcp-server/issues/33)).
- **Vehicle identity** resolves trip, route, and headsign from the canonical active trip ([#34](https://github.com/cyanheads/onebusaway-mcp-server/issues/34)); missing-position counts disclose agency-wide omissions and resolved route matches ([#41](https://github.com/cyanheads/onebusaway-mcp-server/issues/41)).
- **Vehicle orientation** describes counter-clockwise degrees from east without converting the number ([#37](https://github.com/cyanheads/onebusaway-mcp-server/issues/37)).
- **Route schedules** resolve reference metadata before legacy/grouping fallbacks without enumerating unscheduled reference trips ([#39](https://github.com/cyanheads/onebusaway-mcp-server/issues/39)).
- **Block configurations** retain every alternative in upstream order and describe service IDs as calendar conditions ([#42](https://github.com/cyanheads/onebusaway-mcp-server/issues/42)).
- **MCPB cleanup** preserves SDK runtime skill modules while removing dependency documentation and build-only files ([mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794)).
